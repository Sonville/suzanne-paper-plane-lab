# Suzanne 紙飛機探索實驗室

以 Sonville 的 Suzanne 紙飛機飛行實驗室為起點，加入多機型、機翼調校、發射機構、五種場景與模型匯入。保留原有的基準試飛、先預測再試飛、前後結果比較、受力箭頭與慢動作重播。

本作品用於課堂觀察變因，是簡化教學模型，不能視為經實測校正的飛行預測工具。

## 操作方式

1. 在「機身」選擇蘇珊滑翔翼、經典飛鏢、獵鷹或太空梭。
2. 在「試飛」設定迴紋針數量、位置、投擲角度、力道、風向及天氣。
3. 在「發射」選擇手拋、平坦甲板、橡皮筋或雙軌；設定 0–30m 高度。
4. 在「場景」選擇實驗室、沙漠、草原、都市或月球。
5. 建立基準試飛。每次只改一個參數，先選擇預測，再比較結果。
6. 使用側視、跟隨、自由環繞與塔台觀測；自由環繞可在飛行中拖曳與縮放。
7. 「匯入」提供檔案選擇及格式說明。右上角亦有快速入口。

## 改良內容

| 類別 | 本版內容 |
| --- | --- |
| 機型 | 四款程序化折紙外形，分別採用不同的簡化翼面積與阻力參數 |
| 調校 | 尾舵、後緣反曲、上反角、翼尖小翼、重心微調、接縫貼平與粗糙度 |
| 動畫 | 機翼平滑折動、迴紋針滑入、CG 綠環移動、骨刀壓痕、橡皮筋回彈 |
| 發射 | 手拋與三種發射台、可調高度、橡皮筋張力；支架位於甲板下方 |
| 場景 | 五種主題，每種含五類佈景，沿航道兩側分散配置；風扇與風車旋轉 |
| 月球 | 重力 1.62 m/s²、零空氣密度，無風雨、升力或阻力，使用彈道計算 |
| 觀測 | 六種局部特寫、自由環繞、側視、跟隨與塔台；即時距離、高度與速度回饋 |
| 匯入 | 紙飛機模型、全景背景、多個地景物件；提供錯誤提示、清除與恢復功能 |
| 品質 | 模型最低點防穿模、機首與運動方向統一、顯示放大不改變物理結果、手機排版 |

介面中的「飛更遠／飛更高」只切換學習目標與結果顯示，不會偷偷改變飛行計算。機型、配重、翼面調校與發射條件才會改變結果。

## 本機啟動

建議使用 Node.js 22 與 pnpm 10（與 GitHub Actions 一致）。

```bash
pnpm install --frozen-lockfile
pnpm dev
```

正式建置與預覽：

```bash
pnpm test
pnpm build
pnpm preview
```

亦可使用 npm install、npm run dev、npm test、npm run build；專案鎖定檔與部署流程使用 pnpm，協作時優先保持一致。

## 原始碼

- `index.html`：Vite 網頁入口與 React 掛載容器。
- `src/main.jsx`：主介面、Three.js 場景生命週期、天氣、試飛、比較、重播與素材載入流程。
- `src/simulation.js`：可獨立測試的飛行估算、重心、機型及環境參數。
- `src/lab-scene.js`：可調紙飛機、發射台、五種佈景、模型解析與音效。
- `src/LabControls.jsx`：機身、發射、場景、匯入面板與格式說明對話框。
- `src/styles.css`：桌面與手機介面樣式。
- `tests/simulation.test.js`：飛行、月球彈道、極端參數、幾何間距與模型貼地檢查。
- `.github/workflows/pages.yml`：main 推送後建置並部署 GitHub Pages。
- `assets/flight-simulator*.png`：保留的原版參考截圖，並非本版驗收圖。

## 模型及圖片格式

- 飛機與地景支援 `.glb`、資源內嵌的 `.gltf`、`.obj`，每檔最多 20 MB。
- GLTF 需自包含；不載入外部 URL、材質或相鄰檔案。OBJ 使用模型幾何，不載入外部 MTL。建議使用 GLB。
- 飛機來源座標：機首 +Z、機頂 +Y。匯入時轉為本專案 +X 前進方向，並自動縮放。
- 地景每次最多 10 個，總數最多 30 個。依邊界框縮放與貼地，分散於航道兩側。
- 天空支援 2:1 等距柱狀 JPG／PNG，上限 10 MB、4096×2048。切換場景會恢復預設天空。
- 所有匯入檔案在本機瀏覽器解析，不上傳；重新整理後不保存。

## 模擬與功能限制

- 飛行係數、重心、粗糙度及翼尖效果是教學近似，並非完整 CFD 或六自由度飛行模型。
- 下雨主要改變視覺效果；颱風另外影響軌跡。場景沒有真實氣象資料。
- 橡皮筋採用假設彈簧常數與效率估算初速，不是實物發射器校正結果。甲板、導軌不另加推進力。
- 自訂飛機只替換外觀，飛行採選定內建機型的參數；無法自動分辨匯入模型的尾舵與翼尖。自訂模型不提供重播快照。
- 地景是裝飾物件，沒有飛機與地景碰撞；全景圖也不會改變物理環境。HDR 與自訂地形物理不在本版範圍內。
- 「顯示尺寸」只改視覺，模型與場景採示意比例。高度以發射／地面基準計，視覺加入最低點防穿模間距。
- 飛行時間最長計算 60 秒；若未落地會明確標示。動畫為便於觀察而調整播放時長，不代表真實秒數。
- 歷史僅保留前一次與本次結果，沒有多筆保存或 CSV 匯出。

## 驗證

自動檢查涵蓋：四機型與五場景、地面與高處發射、月球解析彈道對照、風雨在真空無效、顯示尺寸不改物理、彈射張力、左右配重對稱、極端參數、負上反角離地間距、匯入模型正規化與貼地。

人工操作驗收可依序檢查：

1. 基準試飛完成後顯示數據，再次試飛需先選預測。
2. 改一個參數，試飛後顯示與前次差異；重播恢復該次設定。
3. 切換四機型、調整翼面、播放壓痕，檢查鏡頭與動畫。
4. 設 0m 甲板、負上反角與多枚迴紋針，檢查停靠與著陸。
5. 切換五場景；月球的風雨控制停用。
6. 匯入有效 OBJ／GLB，並以損壞檔案確認失敗訊息；恢復內建機型。
7. 以窄螢幕確認頁面可捲動、控制可使用。
